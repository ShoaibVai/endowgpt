# endowGPT — Final Report

Build completed Nov 11, 2026. A branded, self-hosted ChatGPT-style workspace
(artifacts, Canvas-style document editor, RAG) built on LibreChat v0.8.9-rc1
and its RAG API.

## What was delivered

### Deployment (root)
- `docker-compose.yml` — one-command stack: `api` (endowGPT app), `mongodb`,
  `meilisearch`, `rag_api`, `vectordb` (pgvector), `ollama`, `ollama-init`
  (pulls `nomic-embed-text` once, gating rag_api). Health checks on all
  services; named volumes for all state; only port 3080 exposed.
- `.env.example` — every variable documented; `.env` (gitignored) holds
  generated secrets; `OPENCODE_API_KEY` is the only model credential.
- `scripts/brand-assets.mjs` — reproducible brand pipeline; `scripts/smoke.mjs`
  — boot/config/branding/documents/models smoke test.

### Models
- Single OpenAI-compatible endpoint at `https://opencode.ai/zen/v1`, credential
  from env only. Model specs: **endowGPT Fast (DeepSeek)**
  (`deepseek-v4.1-flash-free`, default) and **endowGPT Flash (GLM)**
  (`glm-5.3-flash-free`), both with `artifacts` + `fileSearch` enabled; title
  generation pinned to the GLM model; streaming on; friendly error copy.

### Branding (M2)
- Palette applied through the inline deployment theme in `librechat.yaml`
  (light/dark token sets). No custom palette CSS outside two documented
  feature-local cases (splash media backdrop, suggestion mark colors).
- Logo assets: discovered the pack's inverted filename mapping and the
  Chromium viewBox-crop bug; served SVGs keep the full square canvas and crops
  are CSS; raster favicons/PWA icons/marks are generated by the pipeline.
- Logo splash: once per session, muted/autoplay/playsInline, skippable,
  static fallback under `prefers-reduced-motion`, gated by
  `interface.logoSplash`.
- Welcome text, starters ("Draft a document", "Build an interactive page",
  "Summarize a file"), footer with `/credits` attribution page (upstream
  licenses reproduced). English locale swept; remaining `librechat*` strings
  are config-file/worker names and license text.

### Artifacts + document editor (M3–M5)
- New `application/vnd.endowgpt.document` artifact type with prompt guidance,
  aliases (`document`, `doc`), row kind, and panel dispatch to TipTap.
- Editor: headings, bold/italic/underline/strike, lists, tables, links, code
  blocks, undo/redo; Markdown import/export via marked↔turndown; DOCX
  (`docx`), PDF (`jspdf`), copy-rich-text exports.
- Inline AI selection edits: BubbleMenu floating toolbar (Improve/Expand/
  Shorten/Fix grammar/Translate/Tone submenu/Custom), word-level diff rendered
  as `endowInsert`/`endowDelete` marks with Accept/Reject; deterministic
  `/api/documents/ai-edit` call (no tool-calling dependency), model allow-list,
  per-user hourly limiter, safe error codes localized.
- Persistence: `/api/documents` (Mongo) keyed per user + conversation +
  artifact; every save snapshots a version (cap 50, configurable); conflict
  detection via `baseVersionId` → HTTP 409; restore appends a pre-restore
  snapshot (history never rewritten); autosave serializes saves to keep the
  message-artifact `original` matching; versions drawer with preview.
- `/documents` list page and `/documents/:conversationId/:artifactId`
  full-page editor; `FilePreviewDialog` "Edit this document" imports
  extracted file text into a store-backed document.

### RAG (M6)
- Stack verified live: pgvector tables created, `nomic-embed-text` pulled via
  ollama-init, embeddings initialized (Ollama), `/health` UP, and LibreChat
  reporting "RAG API is running and reachable". File search runs through the
  ephemeral agents created by the `fileSearch` spec capability; citations UI
  and "Edit this document" import are in place.

## Known limitations / notes

1. **Model smoke depends on upstream quota** — the provided key hit OpenCode's
   free-tier limit during verification; rerun `node scripts/smoke.mjs` after
   the reset for the full two-model pass (the script classifies this as SKIP
   with the reason, not a failure of the deployment).
2. **Documents on a fresh ("new") conversation** are stored under the literal
   conversation id `new` until the conversation gets its real id; the
   `/documents` list may then show a stale key alongside the re-keyed one.
3. **Selection edits are inline-only** — a selection spanning paragraphs is
   deliberately out of scope (block-level rebuild); the toolbar hides itself
   for those selections.
4. **Ai-edit prompt caching** — each selection edit is a standalone
   completion; long passages cost full prompt tokens.
5. **`SCHEDULES_SINGLE_PROCESS=true`** asserts the compose deployment runs one
   replica; multi-replica setups need the shared stream store instead.
6. **Pre-existing upstream typecheck noise** in untouched spec files
   (implicit-any in tests) was left as-is to keep the diff surface minimal.
7. **Suggestion mark commands removed** — while adding the M7 tests, both
   suggestion marks were found registering a command under the same name
   (`setEndowSuggestion`), where the `endowDelete` registration silently won.
   Production applies marks through raw transactions, so rendering was never
   affected; the dead command surface was removed rather than kept broken.
   Accept/reject now also preserves formatting a user adds on top of a
   pending suggestion (only the suggestion marks are stripped).
